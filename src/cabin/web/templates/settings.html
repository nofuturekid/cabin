Trust the reverse proxy

Tick this only if cabin is reached exclusively through a reverse proxy you control. The audit log then records the first address from the X-Forwarded-For header instead of the address the request arrived from. Without a proxy in front, anyone can send that header and choose which IP the log blames.

ACME

Let clients such as certbot or acme.sh request certificates from cabin automatically. While this is off, every /acme/… address answers as if it did not exist. Set a base URL above as well — that is the address clients are given.

The directory URL, external account keys and client setup snippets live on the ACME page.

ACME validation

To prove a name belongs to them, clients let cabin fetch a file over HTTP, read a DNS record, or open a TLS connection — so an ACME order decides where cabin connects. Cabin never connects to loopback, link-local or multicast addresses; private addresses are the normal case for an internal CA and are allowed unless you untick this.

For dns-01, cabin asks this host's own resolver by default. Name one or more resolvers here (IP addresses, comma-separated) if the internal zone is only visible to a different one.

MCP
