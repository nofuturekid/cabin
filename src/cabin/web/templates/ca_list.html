Import a cross certificate

A cross certificate produced elsewhere, for a root already on this instance -- no key, no name. cabin checks that it really is another certificate for that root, the same subject and the same public key, and refuses it otherwise: a mistyped paste must not staple a stranger's CA into the chain cabin serves to every client.
