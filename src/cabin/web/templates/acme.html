Client setup

The --eab-* flags are only needed while external account binding is required; without it, drop those two lines.

certbot

certbot certonly --standalone \
  --server {{ snippet_directory }} \
  --eab-kid {{ snippet_kid }} \
  --eab-hmac-key {{ snippet_hmac }} \
  -d nas.lan

acme.sh

acme.sh --register-account \
  --server {{ snippet_directory }} \
  --eab-kid {{ snippet_kid }} \
  --eab-hmac-key {{ snippet_hmac }}
acme.sh --issue --standalone --server {{ snippet_directory }} -d nas.lan

cabin's root certificate has to be in the trust store of whatever will talk to the issued certificate — download it from CA.
